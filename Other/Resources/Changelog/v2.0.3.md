# Release notes

## Changes

- updated dependencies
- Updated the versions of the used images
- Removed the configuration of GitVersion, which is not used anymore
- Fixed a latent crash in the integrity-check by removing an invalid default-value of an internal parameter
- Replaced the deprecated `datetime.utcnow()` in the logging to avoid deprecation-warnings and a future breakage
- Fixed two testcases which created their test-environment inside the try-block, so that a failing setup could hide the original error
